# Map Notes (OpenStreetMap) — заметки на карте для Obsidian

Плагин для [Obsidian](https://obsidian.md), который превращает заметки в точки на карте. Ставите метку, привязываете к ней заметку — и прямо на карте раскрывается карточка с её содержимым, соединённая с меткой линией. Карта на данных OpenStreetMap, без ключей API и лимитов.

## Возможности

- **Метки с заметками.** Клик по метке открывает на карте карточку с отрендеренной заметкой (ссылки, картинки, форматирование). Карточку можно перетаскивать за заголовок и менять размер — она связана с меткой пунктирной линией и двигается вместе с картой. Саму метку тоже можно перетащить — или закрепить на месте, чтобы случайно не сдвинуть.
- **Несколько способов добавить метку:** кнопка «Метка» и клик по карте, правый клик → «Добавить метку здесь» или перетаскивание заметки из проводника Obsidian прямо на карту.
- **Поиск адреса.** Введите адрес как привыкли («г.Самара ул.5-я просека 95Б») — карта перелетит к нему, и туда можно сразу поставить метку.
- **Связи между метками.** Пунктирные линии от одной метки к другой: направление (стрелка в одну, другую или обе стороны, без стрелок), свой цвет и надпись на линии.
- **Список меток справа** — выезжающая панель с поиском, папками (с вложенностью) и drag & drop.
- **Плавный перелёт.** Клик по метке в списке — карта перелетает к ней и ставит в центр видимой области. Чем дальше метка, тем дольше перелёт; скорость камеры настраивается.
- **Скрытие меток и целых папок** с карты (значок глаза в списке).
- **Цвет метки** — палитра или любой цвет (пипетка, HEX, R/G/B).
- **Подложки карты:**
  - OpenStreetMap (растровая);
  - OpenFreeMap (векторная) — три темы («Минимализм», «Подробная», «Яркая»), цветовые схемы «Светлая», «Темная» и «JoJo's Bizarre Adventure», 3D-здания, русские или английские подписи;
  - свой URL тайлов.
- **Офлайн-режим.** Скачивание видимой области карты для работы без интернета и кнопка «Обновить» для повторного скачивания.

## Установка

### Вариант 1. Из релиза (проще всего)

1. Откройте страницу [последнего релиза](../../releases/latest) и скачайте три файла: `main.js`, `manifest.json`, `styles.css`.
2. Откройте папку своего хранилища Obsidian и перейдите в `.obsidian/plugins/`.
   Папка `.obsidian` скрытая: в Finder нажмите `Cmd + Shift + .`, чтобы её увидеть; в Windows включите «Скрытые элементы» на вкладке «Вид».
3. Создайте в ней папку `osm-map-notes` и положите туда скачанные файлы:
   ```
   <хранилище>/.obsidian/plugins/osm-map-notes/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
4. В Obsidian откройте **Настройки → Сторонние плагины**. Если включён «Безопасный режим», выключите его.
5. Нажмите кнопку обновления списка плагинов и включите **Map Notes (OpenStreetMap)**.
6. Откройте карту — значком метки на левой панели или командой «Открыть карту» (`Cmd/Ctrl + P`).

### Вариант 2. Через BRAT

Если у вас установлен плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat): **BRAT → Add Beta plugin** и вставьте адрес этого репозитория. BRAT сам скачает релиз и будет обновлять плагин.

### Вариант 3. Сборка из исходников

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
git clone <адрес этого репозитория>
cd obsidian-osm-map-notes
npm install
npm run build
```

После сборки скопируйте `main.js`, `manifest.json` и `styles.css` в `<хранилище>/.obsidian/plugins/osm-map-notes/` и включите плагин, как в варианте 1.

Для разработки: `npm run dev` пересобирает `main.js` при каждом изменении исходников.

### Обновление

Замените три файла в папке плагина на новые из релиза, затем в «Сторонних плагинах» выключите и снова включите плагин. Ваши метки, папки и настройки хранятся в `data.json` в той же папке — его не трогайте.

## Как пользоваться

| Действие | Как сделать |
|---|---|
| Открыть карту | Значок метки на левой панели или команда «Открыть карту» |
| Найти адрес | Поле «Поиск адреса…» вверху карты → Enter → «Добавить метку» |
| Поставить метку | Кнопка «Метка» → клик по карте, или правый клик по карте, или перетащить заметку на карту |
| Открыть / свернуть карточку | Клик по метке |
| Переместить карточку | Перетащить за заголовок; размер — за правый нижний угол |
| Переместить метку | Перетащить метку |
| Связать две метки | Правый клик по метке → «Связать с меткой…» → клик по второй метке |
| Направление, цвет, надпись связи | Клик по линии связи |
| Закрепить метку | Правый клик по метке → «Закрепить на месте» |
| Закрепить все метки | Значок замка слева от кнопки списка меток |
| Перелететь к метке | Клик по метке в списке справа |
| Скрыть метку или папку | Значок глаза в строке списка |
| Меню метки или папки | Правый клик по метке на карте или в списке |
| Наклон и поворот (3D) | Правая кнопка мыши или Ctrl + перетаскивание |
| Офлайн-режим и скачивание | Кнопка «Онлайн / Офлайн» на панели карты |

Настройки подложки, темы, цветовой схемы, 3D-зданий, языка подписей и постоянного показа названий меток — в **Настройки → Map Notes (OpenStreetMap)**.

## Где хранятся данные

- Метки, папки и положение карточек — в `.obsidian/plugins/osm-map-notes/data.json`. При переименовании или перемещении заметок ссылки обновляются автоматически.
- Скачанные для офлайна области — локально на устройстве (IndexedDB) и не синхронизируются между устройствами.

## Ограничения

- Сервер тайлов OpenStreetMap не рассчитан на массовое скачивание, поэтому для офлайна доступна детализация до 16-го масштаба и не больше 30 000 тайлов на область.
- Векторную карту скачать нельзя: в офлайн-режиме показываются скачанные растровые области OpenStreetMap.
- Перевод подписей берётся из данных OpenStreetMap. Если у объекта нет русского названия, показывается английское, а затем местное.
