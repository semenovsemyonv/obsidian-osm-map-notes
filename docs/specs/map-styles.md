# Подложки и стили

## Подложки (`settings.tileProvider`)
- `osm` — растровая OpenStreetMap (`tile.openstreetmap.org`, maxzoom 19).
- `vector` — OpenFreeMap, стиль грузится с `https://tiles.openfreemap.org/styles/<theme>` (кэш в памяти, при ошибке — сброс и откат на OSM с уведомлением).
- `custom` — свой XYZ-шаблон; ключ провайдера `custom:<url>`.

## Векторные темы (`vectorTheme`)
`positron` — «Минимализм», `liberty` — «Подробная» (по умолчанию для неизвестных), `bright` — «Яркая».

## Обработка стиля (`loadVectorStyle`)
1. Глубокая копия сырого стиля.
2. Язык подписей (`labelLang`: `ru`/`en`): заменяется `text-field` у symbol-слоёв, где используется `name`; `ref`/`housenumber` не трогаются. Фоллбэк: выбранный язык → английский → местное название.
3. Цветовая схема (`colorScheme`, для всех тем):
   - `light` — исходные цвета;
   - `dark` — перекраска в тёмную гамму (оттенок ~222°);
   - `jojo` — фиолетовая земля, золотые магистрали, розовые обводки, бирюзовая вода, жирные подписи крупных городов; в UI — класс `gis-scheme-jojo` и анимированные «ゴ» по краям карты.
4. Здания: цвет плоских зданий и крыш считается от фона в OKLab (меняется только светлота, шаги на схему в `BUILDING_STEPS`, рампа по масштабу 13→17).
5. Встроенные `fill-extrusion`-слои темы удаляются всегда (рисуют тёмные стены даже без наклона). При `buildings3d` добавляется свой слой `map-notes-buildings-3d` (fill-extrusion).

## 3D-камера
- Активна только при vector + online + `buildings3d` (`plugin.is3d()`).
- Включает наклон/поворот (правая кнопка, Ctrl+перетаскивание, touch), начальный наклон 55°, `maxPitch` 70.
- При выключении — анимированный возврат к pitch 0, bearing 0, вращение отключается.

## Смена стиля
Любое изменение настроек подложки → событие `tiles-changed` → `buildStyle` → `map.setStyle(style, { diff: false })` + пересчёт режима камеры и оформления.
