# Спецификации

Краткое описание того, как плагин должен работать. При изменении поведения — обновлять соответствующий файл.

- [features.md](features.md) — функциональность и UI: метки, карточки, список, меню, команды, настройки.
- [data-model.md](data-model.md) — формат `data.json`, инварианты, миграции.
- [offline.md](offline.md) — офлайн-режим: области, скачивание, протокол `mapnotes://`, IndexedDB.
- [map-styles.md](map-styles.md) — подложки, векторные темы, цветовые схемы, 3D-здания.
