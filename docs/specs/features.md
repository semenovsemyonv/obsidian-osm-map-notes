# Функциональность

## Вид «Карта»
- Тип вида `gis-map-notes-view`, открывается в отдельной вкладке (один экземпляр: повторное открытие активирует существующую).
- Камера (центр, масштаб) сохраняется в `lastCamera` на `moveend` и восстанавливается при открытии.
- Если WebGL недоступен — заглушка с кнопкой «Открыть настройки».
- Тулбар: «Метка» (режим добавления, Esc — отмена) и кнопка режима «Онлайн/Офлайн» (открывает модалку офлайн-карт, показывает % скачивания).
- Внизу слева: масштабная линейка и навигация (компас — только в 3D).

## Поиск адреса
- Поле «Поиск адреса…» в тулбаре; запрос по Enter (не при наборе — правила Nominatim), Esc закрывает список.
- `geocoder.ts`: адрес нормализуется (`normalizeAddress`: убираются «г.», «ул.», «д.», «кв. N», раскрываются «пр-т», «пер.», «б-р», «наб.», «пл.», «ш.», «обл.», «р-н»; «д. 12, корп. 2» → «12к2»), затем параллельно запрашиваются Nominatim и Photon. Результаты объединяются (дубликаты ближе 30 м с тем же названием отбрасываются), выше — результаты с номером дома из запроса; максимум 8.
- Nominatim: не чаще 1 запроса в секунду, `User-Agent` плагина, `accept-language` = язык подписей.
- Лучший результат показывается сразу, список остаётся открытым для выбора. Найденная точка — временная пульсирующая метка с пузырём: название, адрес, «Добавить метку», крестик.
- Камера: дом — масштаб не меньше 17; объект с большой рамкой (город, улица) — `fitBounds` целиком. Отступы учитывают ширину открытого списка меток.
- «Добавить метку» (в пузыре или «+» в строке результата) открывает выбор заметки с подставленным названием адреса; после добавления временная метка убирается. Очистка поля тоже убирает её.

## Метки
- Добавление: режим «Метка» + клик; правый клик → «Добавить метку здесь»; перетаскивание `.md` из проводника Obsidian на карту.
- При добавлении (кроме drop) — `NotePickerModal`: выбрать заметку / создать новую / без заметки. Новая заметка создаётся в папке для новых файлов с frontmatter `location: "lat, lng"` и заголовком.
- Цвет новой метки — по кругу из `MARKER_COLORS`; карточка новой метки открыта.
- Метку можно перетаскивать; клик — открыть/свернуть карточку. Закреплённая метка (`locked`, значок замка на «головке») не перетаскивается; попытка перетащить её не считается кликом.
- Общий замок (`settings.markersLocked`) — кнопка слева от ручки «Список меток», едет вместе с панелью. Запрещает перетаскивание всех меток, значки и подписи при этом не меняются; клик по метке по-прежнему открывает карточку.
- Название метки показывается при наведении, а при `alwaysShowLabels` — всегда.
- Правый клик по карте без метки: «Добавить метку здесь», «Скопировать координаты» (`lat, lng`, 6 знаков). В 3D меню показывается только если правая кнопка не тянула карту (>5 px).
- Меню метки: открыть/свернуть карточку, скрыть/показать, перейти к метке, открыть заметку, переименовать, привязать/сменить заметку, цвет, закрепить/открепить, связать с меткой, переместить в папку, сбросить положение карточки, удалить (с подтверждением; заметка не удаляется).

## Карточки
- Рендер заметки через `MarkdownRenderer`, обновляется при изменении файла (`vault.modify`).
- Перетаскивание за заголовок (меняет `cardOffset` в пикселях экрана), изменение размера за угол (`cardSize`, через ResizeObserver).
- Пунктирная линия от «головки» метки до ближайшей точки края карточки; если метка под карточкой — линии нет.
- Клик по карточке поднимает её наверх (z-index). Колесо мыши внутри карточки не зумит карту.
- Кнопки заголовка: открыть заметку, меню, закрыть.

## Связи между метками
- Создание: меню метки → «Связать с меткой…» → клик по другой метке. Пока идёт выбор, от метки к курсору тянется пунктир; Esc или клик по карте отменяют. Связать метку саму с собой нельзя, одна пара связывается только один раз (в любом направлении).
- Новая связь: направление «к второй метке» (`forward`), цвет первой метки, без надписи.
- Отрисовка: пунктир между «головками» меток (с отступом `LINK_GAP`), стрелки — SVG-треугольники на концах по направлению, надпись над серединой линии, повёрнута вдоль неё и всегда читается слева направо.
- Связь видна, только если видны обе метки (скрытые метки/папки прячут и связи). Если метки на экране почти совпадают, линия не рисуется.
- Клик или правый клик по линии/надписи → меню: направление (к A, к B, в обе стороны, без стрелок), надпись (пустая — убрать), цвет, перейти к любой из меток, удалить связь.
- При удалении метки удаляются все её связи.

## Список меток (sidebar)
- Выезжающая правая панель, состояние открытости — `settings.sidebarOpen`. Слева от её ручки — кнопка общего замка меток.
- Дерево папок (вложенные), счётчик меток, сворачивание папок (`collapsed`).
- Поиск по имени метки и пути заметки (без учёта регистра).
- Drag & drop меток и папок между папками (нельзя положить папку внутрь самой себя — `isFolderInside`).
- Глаз: скрыть метку или папку целиком; скрытие папки наследуется вложенными.
- Клик по метке — перелёт к ней.

## Перелёт (flyTo)
- Собственная анимация (не `map.flyTo`): центр интерполируется в Меркаторе, масштаб «проседает» посередине при больших расстояниях. Длительность `flyDuration` (500 мс), целевой масштаб `max(текущий, flyZoom=15)`.
- Метка ставится в центр видимой области с учётом ширины открытого списка.
- После перелёта: открыть карточку (если `openCardOnFly`), поднять наверх, пульсация метки. Для скрытой метки — уведомление и без открытия.

## Команды
- `open-map` — «Открыть карту» (также иконка на ленте).
- `toggle-marker-list` — показать/скрыть список (только когда активен вид карты).
- `show-all-markers` — снять скрытие со всех меток и папок.

## Настройки
Подложка (OSM / OpenFreeMap / свой URL); для векторной — тема, цветовая схема, 3D-здания, язык подписей; для своего URL — шаблон `{z}/{x}/{y}` (применяется только валидный); режим карты + кнопка «Офлайн-карты…»; «Отображать название метки всегда»; «Открывать карточку после перелёта».

## Переименование заметок
`vault.on("rename")` обновляет `notePath` у меток — как для самого файла, так и для всех файлов внутри переименованной папки.
